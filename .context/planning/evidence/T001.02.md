## Failures and corrections along the way

- **Maven Central's SHA-1 search misses artifacts.** The first real run found only 14 Central matches, and not Guava or jsoup, though both are on Central with matching `.sha1` files. `search.maven.org` returned `numFound: 0` for them:

  ```
  == com.google.guava_33.7.1.jre.jar 77e37866fb969b4ff6710faaefd3a86067730ada
  {"responseHeader":{...},"response":{"numFound":0,"start":0,"docs":[]}}
  == org.jsoup_1.23.2.jar 514805efcc430bfb04e82f20bb998e39e3fd5c9c
  {"responseHeader":{...},"response":{"numFound":0,"start":0,"docs":[]}}
  $ curl -fsS https://repo.maven.apache.org/maven2/com/google/guava/guava/33.7.1-jre/guava-33.7.1-jre.jar.sha1
  77e37866fb969b4ff6710faaefd3a86067730ada
  ```
