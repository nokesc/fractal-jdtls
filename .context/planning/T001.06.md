# T001.06 — Integration suite and retiring the seed

Step 6 of [T001](T001.md).

## Why now

"Tested together" means this suite passes against the pinned release. It's also what reveals a break after any later upgrade of JDT LS, m2e or Maven.

## Depends on

T001.05.

## Design

- [design.md](../design.md) §8.
- The spike's `scripts/lsp_driver.py`, `make-fixture.sh`, `run-all.sh` and `fixture/`, together with its `FINDINGS.md` runs 01, 05 and 06.

## Changes

- **Port the driver and fixture into `tests/`,** with the fixture POMs kept as `pom.xml.fixture`. Replace everything the spike driver took from its environment: the `~/.local/bin/jdtls` default, `JDTLS_DATA`, `SPIKE_HOME`, the spike agent options and the `spike.*` trace format.
- **Each test:**
  - builds the release zip;
  - installs it into a scratch root;
  - creates a scratch main checkout with two linked worktrees;
  - launches through `bin/jdtls`, with an explicit `-data` and the agent's diagnostic log enabled through `--jvm-arg`;
  - uses a scratch Maven local repository through `java.configuration.maven.userSettings`, never `~/.m2` (design §8).
- **Scenarios:**
  - import, edits and reimport, matching run 05;
  - restart on the same workspace, matching run 06;
  - a control run without the agent, through a test-only launch path, matching run 01.
- **Add the suite to `mise run validate`,** with a separate task to run it alone.
- **Retire the seed:**
  - move `FINDINGS.md` to `.context/research/jdtls-worktree-spike.md`, fixing its links;
  - delete `.context/spike/`;
  - update links in the design and the tasks.

## Acceptance

Record real output for each item.

- **Import, edits and reimport:** each worktree's `harness-app` resolves its own `harness-contract`. The edited worktree's diagnostics match run 05, and no library entry points into another worktree. The diagnostic log shows every GAV lookup with a requester, and every final choice in the requester's worktree.
- **Restart:** the same project names and classpaths. The diagnostic log has no naming events, so no project was re-created, and shows all six hooks in place.
- **Control:** without the agent, the duplicate-coordinates import failure appears.
- **Maven isolation:** the scratch Maven repository holds the fixture's plugins.
- The full `mise run validate` passes, with its wall time recorded.
- `git grep -n "spike/"` finds no remaining links to the deleted seed.

## Out of scope

- Adding and removing workspace folders at runtime (design §10). Record it as a known gap in the README.
