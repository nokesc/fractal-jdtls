# T001 — The first release: verified JDT LS 1.63.0 with the worktree agent

Builds everything in [design.md](../design.md), starting from the JDT LS worktree spike. Its seed was retired in T001.06; its findings are [.context/research/jdtls-worktree-spike.md](../research/jdtls-worktree-spike.md).

## How the series works

- **The spike is a seed, not the product.** Tasks read it where it is, and port what they need into the repository's own structure. The last task before the release removes the seed, and keeps `FINDINGS.md` as research evidence.
- **Tasks are ephemeral.** The design and the code are authoritative. Once a task is done, the repository must stand on its own without it: whatever a task decided or learned that matters ends up in the code, tests, docs or design.
- **Evidence:** each task records the real output of every acceptance item in `.context/planning/evidence/T001.NN.md`. That file is committed with the work, in one commit whose subject starts `T001.NN: `.
- **Nothing is tagged, pushed or published by an agent.** Chris tags the release after reviewing the series.
